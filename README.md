# Attendance Forecast (Android)

1. Create a new empty repository on GitHub (private is fine).
2. Upload everything in this folder to it, including the hidden `.github` folder.
3. Open the repository's **Actions** tab. The "Build APK" run starts on its own (about 3 to 5 minutes).
4. When it shows a green tick, open the run and download **AttendanceForecast-apk** from Artifacts.
5. Unzip it, copy `app-debug.apk` to your phone and open it. Allow "install unknown apps" for your file manager or browser when asked.

The app works offline. Your credits and numbers are stored on the phone only.
